# Security Policy

## Sicherheitsprobleme / Security issues

Bitte veröffentliche vermutete Sicherheitslücken **nicht als öffentliches
Issue**. Nutze stattdessen GitHubs Funktion für vertrauliche Meldungen:

**[Sicherheitsproblem vertraulich melden](https://github.com/Maikell84/Starport-Tycoon/security/advisories/new)**

Beschreibe das Problem, mögliche Auswirkungen, betroffene Versionen und – wenn
vertretbar – die Schritte zur Reproduktion. Veröffentliche keine Daten anderer
Personen und führe keine Tests durch, die Systeme, Konten oder Daten Dritter
beeinträchtigen könnten.

Please do **not** disclose suspected vulnerabilities in a public issue. Use
[GitHub's private vulnerability reporting](https://github.com/Maikell84/Starport-Tycoon/security/advisories/new)
and include the affected version, impact, and safe reproduction steps. Do not
access, modify, or disclose other people's data.
